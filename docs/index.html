scScale

Fit empirical or spike-model scaling laws for matched single-cell modalities.

Tutorials

Empirical Scaling Fit Fit cell-number, UMI-depth, and joint curves directly from sampled MI. Spike Model Fit Fit the Gaussian spike model and inspect its spectrum. UMI Scaling Fit Estimate and visualize RNA scaling across UMI depths. Spike vs Empirical Fit Compare UMI, cell-number, and joint MI scaling side by side.

Quick Tutorial: Empirical Fit

library(scScale)
data(gse164378_3p_citeseq_hvg)
X <- gse164378_3p_citeseq_hvg$rna_counts
Y <- gse164378_3p_citeseq_hvg$adt_counts
n_grid <- c(500, 1000, 2000, 4000)
rates <- c(0.25, 0.5, 0.75, 1)

fit <- scscale_empirical_scaling_fit(
  X, Y,
  n_grid = n_grid,
  sampling_rates = rates,
  r = 12
)

umi <- scscale_predict_empirical_umi(fit, sampling_rate = rates)
cells <- scscale_predict_empirical_cell(fit, n = n_grid)
joint <- scscale_predict_empirical_joint(fit, n = n_grid, sampling_rate = rates)

Quick Tutorial: Spike Model

library(scScale)
data(gse164378_3p_citeseq_hvg)
X <- gse164378_3p_citeseq_hvg$rna_counts
Y <- gse164378_3p_citeseq_hvg$adt_counts
n_grid <- c(500, 1000, 2000, 4000)
rates <- c(0.25, 0.5, 0.75, 1)

fit <- scscale_spike_fit(
  X, Y,
  umi_sampling_rates = rates,
  x_rank = 12,
  y_rank = 12
)

umi <- scscale_umi_scaling(fit, sampling_rate = rates)
cells <- scscale_cell_scaling(fit, n = n_grid)
joint <- scscale_joint_scaling(fit, n = n_grid, sampling_rate = rates)
