UMI-Anchored Effective Scaling With GSE164378

This tutorial fits the five-parameter effective model to RNA–ADT mutual information measured across UMI depths. One additional parameter, \(\gamma\), then calibrates the cell-number response around the known reference cell count.

Empirical UMI calibration

At every UMI depth, empirical MI is calculated with all 4,000 cells and fixed rank-12 RNA and ADT subspaces. The effective aspect ratio uses the 2,000-feature RNA input dimension, \(d=2000\), rather than the retained MI rank.

umi_observed <- scscale_empirical_inu_grid(
  X,
  Y,
  n_grid = n_reference,
  sampling_rates = rates,
  r = mi_rank,
  n_replicates = 3,
  n_workers = n_workers,
  seed = 164378
)

Fit the effective model

The five fitted parameters are \[ (I_\infty,C,\theta_Y,a,b). \] The nonlinear optimizer varies only \((\theta_Y,a,b)\). For each optimizer evaluation, \((I_\infty,C)\) are solved by constrained weighted least squares. The effective signal remains linear, \(q(U)=a+bU\). Only its recoverability at the BBP boundary is smoothed: \[ \theta_X(n,U)=\frac{q(U)}{q(U)+1}G\!\left(q(U);d/n\right), \] \[ G(q;c)= \begin{cases} 0, & q^2\le c,\\ \exp\{-c/(q^2-c)\}, & q^2>c. \end{cases} \] This gate turns on smoothly at \(q=\sqrt{d/n}\), approaches the original strong-signal law, and introduces no new parameter.

fit <- scscale_effective_fit(
  umi_observed,
  d = effective_dimension,
  n_reference = n_reference,
  U_reference = U_reference,
  weighting = "inverse_variance",
  n_starts = 10,
  seed = 164378
)

summarize_mi <- function(data, x) {
  split_data <- split(data$I_empirical, data[[x]])
  data.frame(
    x = as.numeric(names(split_data)),
    I_mean = vapply(split_data, mean, numeric(1)),
    I_sd = vapply(split_data, sd, numeric(1))
  )
}

umi_points <- summarize_mi(umi_observed, "U")
cell_points <- summarize_mi(cell_observed, "n")

umi_curve <- predict(
  fit,
  n = n_reference,
  U = seq(min(umi_points$x), U_reference, length.out = 300),
  type = "all"
)
cell_curve <- predict(
  fit,
  n = seq(min(cell_grid), max(cell_grid), length.out = 300),
  U = U_reference,
  type = "all"
)

The reference count \(n_0=4000\) is fixed by the UMI experiment, not fitted. The cell-number data estimate only \(\gamma\): \[ A_n(U)= \frac{\theta_Yd} {q(U)\{q(U)+1\}\{1-\theta_Yq(U)/(q(U)+1)\}}, \qquad A_n(U)\mapsto\gamma A_n(U). \] Let (I_0) be the empirical MI at the observed reference point ((n_0,U_0)). The cell-number prediction is \[ I_\gamma(n,U)=I_0+C \log\left\{ \frac{1+\gamma A_n(U)/n_0}{1+\gamma A_n(U)/n} \right\}. \] All five UMI-fit parameters remain fixed. Only \(\gamma\) is estimated from cell-number observations; (I_0) is an observed anchor, not another fitted parameter. No BBP indicator or additional gate is applied to this correction.
